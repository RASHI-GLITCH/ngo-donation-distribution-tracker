# NGO Donation & Distribution Tracker

A cloud-oriented web application designed to simplify donation management and distribution tracking for non-governmental organizations (NGOs).

## Overview

The NGO Donation & Distribution Tracker provides a centralized interface for managing donations, browsing NGOs, and monitoring distribution-related information. The project aims to improve transparency, organization, and accessibility in donation management.

## Features

- **Role-based interfaces:** Separate views for donors, NGO administrators, and application administrators.
- **Donation management:** Interfaces for different donation categories, including money, clothes, and food.
- **NGO browsing:** Explore NGOs and their donation requirements.
- **Dashboards and analytics:** Visualize donation-related information through dashboards and charts.
- **Distribution tracking:** Organize allocation and distribution information.
- **Responsive interface:** Built with reusable UI components.

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS
- **UI Components:** Reusable React components
- **Build tools:** Vite and npm

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd quantum-haven
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To create a production build, run:

```bash
npm run build
```
